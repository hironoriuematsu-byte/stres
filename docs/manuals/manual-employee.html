ストレスチェックWeb かんたんマニュアル

従業員向け(受検のしかた)

発行: うえまつ産業医事務所(Mestate LLC) / アプリURL: https://stres.vercel.app

1. はじめに

年1回のストレスチェックを、パソコンやスマートフォンから受検できます。設問数は会社ごとに57問(約10分)または80問(約13分)のどちらかです(画面に表示されます)。どちらも高ストレスの判定基準は同じで、80問版では職場環境についての設問が加わります。

プライバシーは守られます。あなたの結果を見られるのは、本人・実施者(医師・産業医 上松 弘典)・実施事務従事者(守秘義務あり)のみです。あなたが同意しない限り、会社に個人結果は提供されません。受検や結果を理由とする不利益な取り扱いは法律で禁止されています。

2. はじめて使うとき(登録は1回だけ)

1会社から配られたURLを開く(QRコードでも可)
会社名と年度が表示された登録画面が開きます。
2メールアドレスとパスワード(8文字以上)を登録する
登録したメールアドレスは、ログインやパスワード再発行で必要になります。忘れないようにメモ等に控えてください。
3届いた確認メールのボタンを押す
「【ストレスチェックWeb】メールアドレスの確認」というメールが届きます。ボタンを押すと登録完了です(届かないときは迷惑メールフォルダを確認)。

3. ログインのしかた(2回目以降)

1https://stres.vercel.app を開く
2メールアドレスとパスワードを入力してログイン
パスワードを忘れたら「パスワードを忘れた方」から再設定できます。
安全のため、ブラウザを閉じるとログアウトされます。また20分間操作がないと自動的にログアウトします。毎回メールアドレスとパスワードでログインしてください。

4. 受検のながれ

1マイページの「ストレスチェックを受検する」を押す
2氏名・部署・性別を入力する
部署は一覧から選びます(一覧にない場合は「その他(直接入力)」で入力できます)。社員番号の入力は任意です。性別は結果票の換算に使用します。
3設問に回答する
A: 仕事について / B: 最近1か月の状態 / C: 周りの方々について / D: 満足度(80問版はさらに E〜H: 職場環境について)。最近1か月のあなたの状態に最も近いものを選びます。深く考えすぎず、直感でかまいません。
4会社への提供に同意するかを選んで送信
同意は任意です。あとからマイページでいつでも変更できます。
5結果がすぐに表示される
「結果票を見る(印刷・PDF)」から詳しい個人結果票を確認でき、印刷やPDF保存もできます。
ストレスチェックは年度内に1回です。受検後は「受検済み」と表示され、結果の閲覧のみできます。間違えて回答してしまった場合は、会社の実施事務従事者に申し出てください(結果を削除してもらうと、同じ年度内に受け直せます)。

5. 高ストレスと判定されたら(産業医面接指導の申出)

高ストレスと判定された場合、医師(産業医)による面接指導を申し込めます。

1結果画面またはマイページの「面接指導を申し出る」を押す
申出フォームが開いた状態でマイページに移動します。
2「相談したいこと・連絡事項」を記入する(任意)
3同意の確認にチェックを入れて「申出を送信する」を押す
チェックを入れないと送信ボタンは押せません。
4受付確認メールがあなたに届く
実施者・実施事務従事者にも自動で通知され、日程等の連絡が来ますのでお待ちください。
申出をすると、結果を会社へ提供することに同意したものとみなされます。厚生労働省の指針(平成30年8月改正の告示)により、面接指導の申出は事業者への結果提供に同意したものとして取り扱われるためです。この説明は申出ボタンのすぐ上にも表示されます。
面接指導を申し出たことを理由とする不利益な取り扱いは、法律で禁止されています。安心してご相談ください。

6. その他できること

やりたいこと操作
過去の結果を見るマイページに年度ごとの結果が並びます。「結果票を見る」でPDF保存も可能
会社への提供同意を変えるマイページの各結果にあるチェックボックスでいつでも変更
結果票からマイページに戻る結果票の下部にある「マイページ」ボタン(「印刷 / PDFとして保存」も下部にあります)
氏名・メールアドレス・パスワードの変更画面右上「アカウント設定」から。メールアドレスを変更すると新しいアドレスに確認メールが届き、確認後に切り替わります

7. 共用パソコンで受検するとき

受検が終わったら、結果画面の「ログアウトして終了」を必ず押してください。次に使う人にあなたの画面が見られるのを防ぎます。
