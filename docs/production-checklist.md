## 1. Supabase を Pro 化する

料金プランは**組織(Organization)単位**です。プロジェクト単位ではありません。

1. https://supabase.com/dashboard → 左上で対象の組織を選択
2. **Organization Settings → Billing → Plan** から Pro にアップグレード
3. **請求先情報(Billing Address / Billing Email)を会社の情報に設定**
   - 会社名: Mestate LLC(うえまつ産業医事務所)
   - 住所: 京都府京都市中京区錦小路通室町西入天神山町280 4階
   - 請求書の宛先メール: 会社のアドレス(例: hironori.uematsu@mestate.jp)
   - 日本の適格請求書(インボイス)登録番号がある場合は Tax ID 欄に登録
4. 支払方法を会社のカードに設定

### Pro 化で得られる主なもの(本運用で重要な順)

| 項目 | Free | Pro |
|---|---|---|
| **プロジェクトの自動停止** | 1週間アクセスがないと**一時停止** | **なし**(常時稼働) |
| **日次バックアップ** | なし | **あり(7日分)** |
| データベース容量 | 500MB | 8GB〜 |
| ログの保持 | 1日 | 7日 |
| サポート | コミュニティ | メール |

- **自動停止がなくなること**が本運用では決定的です(Free のままだと、受検期間が空いた企業でアクセスが途絶えた際にプロジェクトが停止し、受検も結果閲覧もできなくなります)。
- **日次バックアップ**は、5年保存義務のあるデータを扱ううえで必須と考えてください。
- より細かい復元が必要なら PITR(Point in Time Recovery)が有料アドオンとして追加できますが、当面は日次バックアップで十分です。

### 費用の目安

Pro は **$25/月(組織あたり)** + 従量分。**プロジェクトを増やしても組織のプラン料金は1回**です(小さいプロジェクトは追加の compute 料金がかかる場合があります)。
→ **健康管理Web を同じプロジェクトに相乗りさせる方針なら、Supabase の追加費用は実質ゼロです。**

※ 金額は変更される可能性があります。申込画面の表示金額でご確認ください。

## 4. 認証メールを本番仕様にする(重要)

現在、**アカウント登録の確認メール・招待メール・パスワード再設定メールは Supabase の内蔵メール送信**で送られています。内蔵の送信サービスは**開発・検証用**で、送信レートが厳しく制限されています。

> 100名規模の会社で一斉に登録を案内すると、**内蔵メールでは途中から送信されなくなります。**(申出通知メールで以前起きた「実施者にしか届かない」現象と同じ原因の別バージョンです)

### 対応

1. Supabase → **Authentication → Emails → SMTP Settings** で **Custom SMTP を有効化**し、Resend を設定する
   - Host: `smtp.resend.com` / Port: `465`(または 587) / User: `resend` / Password: Resend の API キー
   - Sender: 既に Resend で認証済みの送信元アドレスを使用
2. **Authentication → Rate Limits** の「Emails」上限を、想定する一斉登録の人数以上に引き上げる
3. **Authentication → URL Configuration** の Site URL / Redirect URLs が本番URLになっていることを確認(独自ドメインを設定する場合は手順6のあとに追加)
4. メールテンプレート(Confirm signup / Invite user / Reset password / Change Email Address)の日本語化 ― 未実施であればこの機会に

## 5. Vercel を Pro 化する

Vercel の Hobby プランは**個人の非商用利用向け**です。商用利用は Pro が必要になります。

### 注意点(事前に把握しておくこと)

1. **Pro はチーム(Team)単位**です。個人アカウントのままでは Pro になりません。**チームを作成し、`stres` プロジェクトをそのチームへ移管(Transfer)**します。
2. **移管後もURL(`stres.vercel.app`)が維持されるかを、移管前に必ず確認**してください。移管先でプロジェクト名が使えないと URL が変わります。
   - **すでに配布したQRコード・URLは、URLが変わると使えなくなります**(配布URLは表示時のドメインで生成される仕組みのため、再表示すれば新URLになりますが、印刷済み・送付済みのものは無効になります)。
   - 受検期間中の企業がある場合は、**受検期間の合間に実施**してください。
3. **環境変数**(`NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` / Resend のキー)が移管先に引き継がれているか確認し、足りなければ再登録します。
4. **Deployment Protection** の設定を確認してください。チームのプロジェクトでは保護が既定で有効な場合があり、**本番サイトにログインを要求する設定になっていると、従業員が受検URLを開けません。**
5. 請求先(Billing)を会社の情報に設定します。**Pro はメンバー1人あたりの課金**のため、当面は1人のままにしておくのが経済的です。

### 移管後の確認

- [ ] `https://stres.vercel.app`(または新URL)が**ログインなしで**開く
- [ ] 配布URL(`/join/...`)が開き、新規登録できる
- [ ] 確認メールが届く
- [ ] 受検 → 結果表示までできる
- [ ] 面接指導の申出で、本人・実施者・実施事務従事者の3者にメールが届く

## 6. 独自ドメイン(任意・強く推奨)

`mestate.jp` をお持ちなので、**`stres.mestate.jp`** のようなサブドメインを割り当てられます。

**利点**: 今後 Vercel 側の事情(チーム移管など)でURLが変わっても、**配布済みのQR・URLが生き続けます。**独自ドメインにしておけば、この先の移行でQRを刷り直す必要がなくなります。

手順の概要:
1. Vercel のプロジェクト → Settings → Domains で `stres.mestate.jp` を追加
2. 表示される CNAME レコードを、`mestate.jp` を管理しているDNSに登録
3. 反映後、**Supabase の Authentication → URL Configuration** に新ドメインを Site URL / Redirect URLs として登録
4. 新ドメインで「配布URL・QR」を開き直し、以後はそのQRを配布

> 健康管理Web も同様に `kenko.mestate.jp` を割り当てると、2つのシステムを同じドメイン配下で運用できます。

## 7. Resend の契約判断

- 無料枠は概ね **1日100通 / 月3,000通**、Pro は **$20/月・月50,000通**程度です(申込画面の表示でご確認ください)。
- **Supabase の認証メールを Resend 経由(手順4)にすると、確認メール・招待メールも同じ枠を消費します。**
- 100名の会社を1日で一斉に案内すると、それだけで無料枠の1日上限に達します。
- **判断の目安**: 単発の企業なら無料枠で足ります。**複数社の受検期間が重なる、または1日に100名以上へ案内する見込みが立った時点で Pro に切り替え**てください(月の途中でも即時に反映されます)。

## 8. 健康管理Web の接続(統合運用)

Supabase が Pro で安定していることを確認したうえで進めます。方針は要件定義書(`docs/kenko-kanri-spec.md` 第5章)のとおりです。

1. 健康管理Web は**開発中は無料の別Supabaseプロジェクト**で作り込む(稼働中のストレスチェックWebへの影響ゼロ)
2. 本運用に載せる段階で、`0101_` 以降のSQLを**本番プロジェクト**に適用する
3. テーブルは `hm_` 接頭辞。**既存テーブル・既存ポリシー・既存関数は変更しない**(追加のみ)
4. `companies` と `profiles`、および認証アカウントは**共用**(同じログインで両システムを使える)
5. ストレスチェックの結果は**読み取り専用**で参照。企業側に個人結果を見せる場合は必ず「同意済みのみ」の既存ルートを経由する
6. Vercel は**別プロジェクト**(同じチーム内)。環境変数は Supabase の同じURL/キーを設定
7. Vercel Pro はメンバー課金のため、**プロジェクトを増やしても追加費用はかかりません**
